Backup da BlackBox

Salva no teu computador os 20 amps (capturas), os 20 IRs e os 80 presets da tua BlackBox, antes de instalar o OpenPocket Bass. Esta página só lê a pedaleira: nada é gravado nela.

1 · Conectar

Use o Chrome ou o Edge num computador. Ligue a BlackBox no USB com o firmware oficial, feche o app da M-Vave (M-EFCS) se estiver aberto, e clique em Conectar. O navegador pede acesso ao MIDI: permita.

Este navegador não tem Web MIDI. Use o Chrome ou o Edge num computador.

2 · Fazer o backup

Leva uns minutos. O banco de amps e IRs é lido duas vezes e as duas leituras têm que dar iguais, senão nada é salvo. Não desligue a pedaleira durante a leitura.
